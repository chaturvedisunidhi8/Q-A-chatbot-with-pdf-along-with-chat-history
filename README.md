# Q-A-chatbot-with-pdf-along-with-chat-history
 Project Description:

This project is an AI-powered Question–Answer Chatbot  that allows users to upload PDF documents  and chat with their content intelligently using advanced LLMs (Large Language Models) .

It also maintains chat history  so you can have a continuous, context-aware conversation — just like chatting with a human assistant who remembers previous messages! 

Key Features:

PDF Upload Functionality:
Easily upload any PDF file — the chatbot reads, splits, and understands your document content .

 Conversational Q&A:
Ask questions naturally, and the chatbot will answer using the relevant content from your uploaded PDFs .

Chat History Memory:
Keeps track of your previous questions and answers, maintaining smooth and context-aware interactions .

 Intelligent Responses:
Powered by LLMs for generating accurate, well-structured, and human-like responses .

 User-Friendly Interface:
Built with Streamlit for a clean, interactive, and modern chat experience.

 Tech Stack:

 LangChain – to build conversational chains

 LLM (Groq / OpenAI / LLaMA) – for natural language understanding

 PyPDF / PDF Loader – to extract and process text from PDFs

 FAISS / Chroma – for embeddings and document retrieval

 Streamlit – for web app UI and chat display

 Python – the heart of the project

 Use Cases:

 Study Material Chatbot – Ask questions from textbooks or notes
 Legal Assistant – Query clauses and laws from case PDFs
 Business Reports – Extract insights from long documents
 Research Support – Quickly find answers in research papers
